# VRChatアバターサムネイル撮影管理ツール (Avatar Thumbnail Manager) v3.0

シーン内のVRChatアバターのサムネイルを一括撮影・管理するUnityエディタ拡張です。

メニュー: `ろりぽっぷCANDY > あばたーはぶリスト作成ツール`

## v3.0.1
- 髪型などが写らなくなる問題を修正(MA Bone Proxy / EditorOnly の自動非表示を既定でオフに変更)
- 小物の非表示を「詳細設定」に追加(全体ルール)と、アバターごとの「表示の調整」(隠す/強制表示)を追加

## v3.0の主な変更
- **シーンの見た目そのままで撮影**: Hierarchy上で表示になっているものだけを撮影(MAの小物などが勝手に写り込まない)。シーンで表示/非表示を切り替えるとプレビューにも自動反映
- **リアルタイムプレビュー**: 変更があった時だけ低解像度で再描画する軽量設計。ドラッグで移動/回転、ホイールで前後
- **構図プリセット**: 全身 / バストアップ / 顔アップ(アバターの大きさに合わせて距離を自動調整)
- **背景**: 自動 / 単色 / グラデーション / 透過PNG / 画像。アバターごとの個別設定も可能
- **ポーズ・表情**: アニメーションクリップとブレンドシェイプ、表情プリセットの保存
- **アバターごとのカメラ保存**、**撮影前チェック**(メッシュ無し・マテリアル欠け・見切れ等の警告)
- **比較と復元**: 再撮影前の画像を履歴(最新5件)に保存し、新旧を比較して戻せる
- **リスト**: 検索 / 絞り込み / 並べ替え / タグでグループ / ドラッグ並べ替え
- **全シーン一括撮影**、他シーンの同じアバター画像の流用
- **出力サイズ・形式の選択**(PNG/JPG、1024²・4:3・16:9 など)
- UIを全面刷新(ライト/ダーク両対応)

## 撮影方式
- 既定は「シーンの見た目そのまま」。NDMFビルド結果で撮る方式も設定から選べます(NDMF未導入や失敗時は自動でシーンの見た目にフォールバック)。

## 出力
`Assets/AvatarThumbnailManager/log/[シーン名]/[アバター名].png`(JPG選択時は.jpg)と `AvatarDatabase.json`
履歴は `log/_history/` に保存されます。

## 動作環境
Unity 2022.3 / VRChat SDK(Avatars)。NDMF・Modular Avatarは任意(リフレクション連携のため未導入でも動作)。

## インストール
VCCの「Add Repository」に VPM リポジトリURLを追加し、本パッケージをプロジェクトに追加してください。

## 注意
- 撮影画像とプレビューはアバター表示が異なる場合があります。
- SDKアイコンの自動設定はVRChat SDKの内部APIに依存するためベストエフォートです。
- v2.0の撮影データ(AvatarDatabase.json)はそのまま読み込めます。
